# Análisis de Ventas de Tiendas (2020–2023)

Este proyecto realiza un análisis completo de las ventas de cuatro tiendas a partir de bases de datos en formato CSV. Utiliza `pandas` y `matplotlib` para el procesamiento y visualización de datos.

## 🧾 Descripción

El programa importa datos de ventas desde cuatro fuentes diferentes y ejecuta los siguientes análisis para cada tienda:

- **Facturación total**.
- **Ventas por categoría de producto**.
- **Facturación por categoría de producto**.
- **Calificación promedio de los clientes**.
- **Costo promedio de envío**.
- **Top 10 productos más y menos vendidos**.
- **Facturación trimestral (2020–2023)**.

## 📊 Visualizaciones

El programa genera los siguientes gráficos:

- Gráfico de barras de **facturación total por tienda**.
- Gráficos de torta para mostrar **ventas por categoría por tienda**.
- Gráficos de líneas de **facturación trimestral**.

## 📁 Datos

Los datos se obtienen directamente desde el repositorio oficial de [Alura - Challenge Data Science LATAM](https://github.com/alura-es-cursos/challenge1-data-science-latam) en formato CSV:

- `tienda_1.csv`
- `tienda_2.csv`
- `tienda_3.csv`
- `tienda_4.csv`

## 🛠 Requisitos

- Python 3.7+
- pandas
- matplotlib

📈 Ejemplos de salida

- La facturación total de cada tienda formateada con moneda local.
- Listado ordenado de productos más y menos vendidos.
- Calificaciones promedio de clientes.
- Gráficos detallados para visualizar el rendimiento de cada tienda a lo largo del tiempo.
